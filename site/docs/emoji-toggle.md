# Emoji preference

The persisted emoji preference controls decorative emoji in dialogs and messages. Buttons, field labels, action labels, and accessible names remain factual and emoji-free.

## Configuration and failure modes

Change the switch in Settings. If local storage is unavailable, the shipped enabled value applies only to the visit.

## Security and verification

Emoji never carries meaning alone. Verify enabled and disabled messages, screen-reader names, keyboard focus, and persistence after reload.
