# Bulk actions

Every list supports multi-select, range selection, keyboard selection, page-versus-every-match select all, inverse selection, preview, and honest partial outcomes.

## Configuration and failure modes

Bulk export follows the active filter. Destructive bulk actions route through super confirmation and never silently skip locked or pinned items.

## Security and verification

The preview names exact counts and exclusions. Verify select all scopes, inverse, filtered selection, cancel, partial failures, undo history, and keyboard use.
