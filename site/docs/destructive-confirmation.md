# Destructive confirmation

Destructive actions use an in-site confirmation surface that identifies the action, requires two independent keys, then enables a full-range slider. The action cannot run before all three requirements complete.

## Configuration and failure modes

Emergency exit and Escape cancel safely and return focus. Reduced motion keeps progress readable without animation.

## Security and verification

The control is a decision boundary, not credential storage. Verify untouched, one-key, two-key, partial slider, full slider, cancel, Escape, keyboard, screen reader, and actual success and failure paths.
