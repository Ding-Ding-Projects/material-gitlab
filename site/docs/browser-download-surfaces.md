# Browser download surfaces

A captured download has three distinct working surfaces: Start download before enqueueing, a separate active Downloading dialog with real bytes and cancellation, and an always-on-top non-blocking completion surface.

## Configuration and failure modes

The static site demonstrates the browser-equivalent handoff with a real generated file. Installed-extension provenance remains a separate release proof and cannot be inferred from this equivalent.

## Security and verification

Source, destination, byte count, rate, ETA where known, and outcome remain factual. Verify cancel before start, active cancel, successful download, failure, keyboard use, focus return, and distinct captures of all three states.
