# Local Ollama suite manager

The suite manager uses only the documented local HTTP API for health, version, installed and running models, pulls, copies, deletes, generation, and chat. Offline records and help remain available without a service.

## Configuration and failure modes

The browser surface distinguishes missing, stopped, unhealthy, offline, and healthy states. Model fit remains Unknown unless RAM, VRAM, driver, disk, size, parameters, quantization, and context evidence are present. Harness profiles are allowlisted arrays, never arbitrary shell.

## Security and verification

Loopback responses are bounded and credentials never enter source, arguments, snapshots, logs, exports, captures, or history. Verify pagination evidence, installed reconciliation, all four fit verdicts, pull cancellation and partial results, streamed chat, capability-gated attachments, snapshot, restore, and forced rollback.
