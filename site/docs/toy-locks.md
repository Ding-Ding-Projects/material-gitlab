# Toy locks and Support Tickets

Every rendered element can create its own password or TOTP speed bump through an anchored wizard. Locks are independently enumerable, searchable, removable, and explicitly described as non-security controls.

## Configuration and failure modes

Choose the method and duration from the element context menu. Forgotten credentials route to the fictional local Support Tickets surface, which opens the storage reset location and never deletes data itself.

## Security and verification

No plaintext credential is stored, exported, captured, or logged. The ticket disclosure states that nothing is sent and nobody reads it. Verify independent locks, expiry, relock, search, recovery, disclosure, and no-network behavior.
