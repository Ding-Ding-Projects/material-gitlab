# Accessibility and responsive sizing

The site provides semantic landmarks, names, roles, states, visible focus, reduced-motion behavior, contrast-safe themes, 44-pixel targets, and reflow from 320 pixels upward.

## Configuration and failure modes

Overlays paint their own surfaces, stay inside the viewport, and scroll internally. Wide tables and code scroll inside their container instead of widening the body.

## Security and verification

Accessibility labels never expose private local data. Verify keyboard-only use, screen-reader output, touch use, portrait and landscape, bilingual copy, large text, and 100–200% scaling.
