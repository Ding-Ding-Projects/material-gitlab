# Changelog viewer

The in-site changelog lists every recorded release with version, date, categorized changes, and a validated commit reference. Text search and typed or calendar date ranges compose.

## Configuration and failure modes

Filtered entries can be copied or exported with the active range. An unknown commit is reported rather than guessed.

## Security and verification

Release facts remain exact at every language and tone level. Verify date parsing, invalid partial dates, search composition, commit links, copy, export, and empty results.
