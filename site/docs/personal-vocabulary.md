# Personal vocabulary upload

Settings always show a semantic local JSON picker plus loaded, invalid, replace, clear, and reset states. Original wording remains unchanged until the complete versioned payload validates.

## Configuration and failure modes

The schema bounds bytes, entries, key and value lengths, and rejects unsafe keys and unknown versions without partial application. A corrupt cache fails closed to shipped wording.

## Security and verification

Parsing and replacement are local-only. Payloads, mappings, filenames, paths, and caches never enter logs, exports, history, telemetry, captures, prompts, or repository files. Verify all bounds, reload, corruption, replace, clear, no-network, language, focus mode, and accessible names.
