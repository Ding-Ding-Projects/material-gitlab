# Independent funny levels

English and Cantonese each have a persisted level from 1 to 5. The controls style voice while preserving the exact facts in errors, warnings, and destructive confirmations.

## Configuration and failure modes

Move either slider in Settings. If persistence fails, the shipped level 1 remains in effect. Focus mode suppresses both controls without discarding their saved values.

## Security and verification

Humour never removes affected items, recovery actions, dates, counts, or irreversible consequences. Verify both bounds, independent persistence, all language modes, and restored values after focus mode.
