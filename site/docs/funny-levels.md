# Independent funny levels

English and Cantonese each have a persisted level from 1 to 5. New site preferences and Material settings default both independent levels to **5**. Existing valid saved levels, including level 1, are preserved rather than reset during a normal load.

## Configuration and failure modes

Move either slider in Settings. The site normalizer uses the compiled level 5 when a level is missing or invalid. Missing or unreadable persisted preferences load defaults. Storage availability still determines whether a new choice survives a reload.

These changes correct defaults and preservation behavior; they do not prove that every message renders five distinct tone variants. Full tone rendering and Focus-mode suppression across all application surfaces remain pending. See **Language modes** for the exact verified scope.

## Security and verification

Humour must never remove affected items, recovery actions, dates, counts, or irreversible consequences. The focused localization tests cover all 25 English/Cantonese level combinations in each of the three site language modes. Verify actual wording, both bounds, persistence after reload, and restored values after Focus mode in the live applications before claiming complete support.
