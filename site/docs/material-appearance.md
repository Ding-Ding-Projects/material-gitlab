# Material appearance

The site uses Material Design 3 color roles, typography, shape, elevation, motion, and responsive layout. Every targetable element can open an anchored appearance editor and retain local overrides.

## Configuration and failure modes

Use the context menu or `Alt+Shift+A`. Theme, density, accent, font, spacing, shape, and color controls support per-element and global reset plus redacted import and export.

## Security and verification

Appearance files are bounded and schema-validated. Verify light and dark themes, high contrast, keyboard focus, all color representations, reset, invalid import, narrow layout, and high scaling.
