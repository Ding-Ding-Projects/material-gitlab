# Dim-sum startup surprise

A fresh launch draw may show one bilingual dish name in a non-blocking surface. The draw is exactly 10%, fires at most once, and is suppressed during first run, errors, updates, or active work.

## Configuration and failure modes

There is no off switch. Published dish names and photo links come from the public catalog; if a photo is unavailable, the site omits the image rather than inventing one.

## Security and verification

The feature carries no tracking and stores no visitor preference. Verify draw boundaries, focus behavior, one-per-launch behavior, reduced motion, alt text, and focus-mode suppression.
