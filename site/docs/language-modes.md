# Language modes

The site provides English, Traditional Chinese, and bilingual presentation. The selected mode is stored only in browser storage and applies without a reload.

## Configuration and failure modes

Choose the mode in Settings. If storage is unavailable, English remains active for the current visit. Focus mode temporarily forces English and restores the saved choice after unlock.

## Security and verification

Language selection never changes commands, URLs, identifiers, or external records. Verify all three modes, a reload, focus-mode suppression, keyboard use, and narrow layouts.
