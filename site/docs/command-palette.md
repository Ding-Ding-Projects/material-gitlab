# Command palette

`Ctrl+Shift+F` opens a bounded command palette that indexes destinations, settings, feature pages, tabs, and appearance controls. Selecting a result reveals, focuses, and briefly highlights the exact element.

## Configuration and failure modes

The palette defaults to a bounded card and supports a full-window size. Empty results say so, and hidden or collapsed destinations are revealed without destroying saved preferences.

## Security and verification

Palette search is local. Verify shortcut activation, keyboard traversal, rich controls, every destination, return focus, and narrow layout.
